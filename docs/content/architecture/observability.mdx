# 日志与可观测性

HTTP 请求经过 LogTape 结构化记录并关联 request ID 与 trace/span ID。OpenTelemetry 将 traces 和 metrics 导出到 Collector；Collector 使用 Compose 中的内联配置和官方镜像，不单独构建。

`LOG_STREAM_ENABLED=true` 时，API 注册 `GET /api/logs/stream`。连接建立前依次校验 Session、`platform-admin` 和 fresh session；流提供 `ready`、`log`、`reset`、`overflow` 事件及 heartbeat。它是单进程、有限缓冲、重启即丢失的诊断能力，不作为审计或长期日志存储。
