# 快速开始

项目要求 Node.js 22 或更高版本，并使用 pnpm 11.24.0。

```bash
pnpm install
Copy-Item .env.example .env
just dev
```

`just dev` 会检查依赖，启动 PostgreSQL 和 OpenTelemetry Collector，等待健康后执行 Drizzle、BullMQ migration 与一次性管理员 provisioning，再启动 API、Jobs Worker 和 Web watch 服务。示例管理员是 `admin@example.com` / `Admin123!`，本地可直接使用；真实环境必须替换凭据。长期运行的 API 和 Worker 不会收到管理员初始密码或 migrator 连接串。

基础设施及 provisioning 已经完成时，使用 `just dev-only` 只启动宿主机进程。单独启动基础设施与 provisioning 使用 `just infra-up`；生产形态 Compose 验证使用 `just stack-up`。Swagger UI 位于 `http://localhost:3000/docs`，Web 位于 `http://localhost:5173`。
